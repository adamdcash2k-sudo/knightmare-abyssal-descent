# Knightmare: Abyssal Descent

A pixel-art top-down dungeon crawler for Knightmare Productions. You are MourningStar. Enter the Descent.

## Play

Open `index.html` in any modern browser. No build step, no dependencies, no external assets — the whole game is one self-contained file.

## The Descent

- Hand-designed Castle Knightmare dungeon: entrance, skeleton ambush room, spike-trap corridor, treasure vault, Sigil-Key boss gate, and the Dread Warden's arena
- Enemies: Husk Skeletons, brass clockwork Architect Acolytes, and the abyssal spider boss
- Loot with stat tooltips and equip comparison (ATK / DEF / HP / MP / resists), gold, potions, Scarlet Breath shards
- XP and level-ups, minimap, hotbar, pause, death/retry, victory screen
- Procedural pixel-art sprites and dark-ambient WebAudio sound — everything generated in code

## Controls

- Move: WASD / arrow keys (or the on-screen joystick on touch devices)
- Attack: Space or J (or the attack button on touch)
- Interact / loot / open: E
- Equipment: I

## Stack

Single HTML file. Canvas 2D rendering, WebAudio for sound. No frameworks, no engine, no build tools.
